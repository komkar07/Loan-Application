# In-Principle Loan Approval & Risk Prediction System

An end-to-end Machine Learning web application designed to evaluate loan applications, estimate default risks, and provide transparent risk factor explanations using Explainable AI (XAI).

## 🚀 Features
- **Automated Decisioning:** Generates immediate, in-principle loan approval decisions based on applicant financial profiles.
- **Explainable AI Integration:** Utilizes **SHAP (SHapley Additive exPlanations)** to break down the exact financial metrics impacting the applicant's risk score.
- **Dual-Layer Architecture:** Features a robust Python backend service integrated seamlessly with an interactive UI dashboard.

## 🛠️ Tech Stack
- **Backend Framework:** Flask / Python (Uvicorn ASGI routing)
- **Frontend Dashboard:** Streamlit
- **Machine Learning Core:** Pandas, NumPy, Scikit-Learn, SHAP

## 💻 Local Setup & Installation

Follow these steps to clone the project and run it locally on your machine:

### 1. Clone the Repository
Open your command prompt or terminal and run the following command to download the code:
```bash
git clone https://github.com
```
Once downloaded, open the project folder using **Visual Studio Code**.

### 2. Install Dependencies
Open a terminal instance inside VS Code and install all the required Python packages:
```bash
pip install -r requirements.txt
```

### 3. Launch the Backend API Server
In the same terminal, start up the Uvicorn ASGI server to host your machine learning and prediction logic:
```bash
python -m uvicorn app:app --reload
```

### 4. Launch the Frontend UI Dashboard
Open a **second, separate terminal tab** in VS Code and execute the following command to spin up the interface:
```bash
python -m streamlit run ui.py
```

### 5. Access the Web App
Once both services are running, copy and open the local network link address generated by Streamlit (typically `http://localhost:8501`) in your preferred web browser.
